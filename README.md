## Description 

- The application is designed to manage the library.

- The application is written in Java and uses the JavaFX library.

- The application is based on the MVC model.

- The application retrieves book data from the Google API.

## Installation

1. Clone the project from the repository.

2. Open the project in the IDE.

3. Download the database and run it in MySQLsever/workbench.

4. Exchange to your APIKey by getting it for free from GoogleBookAPI.

5. Update your database password in DataBaseConnectionn.

6. Run the project.

## Usage

1. If you don’t already have an account, please register through the sign-up page.

2. Once your account is created, you can log in to the system using your username and password.

3. From the **Home** page, you can explore book recommendations curated by the system by clicking the **View** button.

4. To search for a specific title, enter the book's name in **the search bar**. Then, select the desired title from the search results to view its details. If the book is marked as *Available*, you can click **Borrow** to check it out.

5. To view the list of books you are currently borrowing, navigate to **MyLibrary**. If you wish to return a book, simply click **Return**, then select the title you'd like to return.

6. You can also discover the most popular books by selecting the **Ranking Books** option.

7. To update your personal information or change your password, go to **Setting**.

8. When you are ready to exit the application, click the **Log Out** button located at the bottom left corner of your screen.

9. If you are the *Administrator*, you can add book to the library and get access to user information, even remove user from system by navigating to **ADMIN**.
